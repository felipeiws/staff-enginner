# Changelog

## 1.0.0 - 2026-08-01

- Adiciona o conector `atlas.github` com descoberta incremental, observações versionadas por commit SHA e histórico de commits.
- Adiciona webhooks HMAC com comparação em tempo constante e rate limit por origem.
- Adiciona abertura idempotente de Pull Request para documentação aprovada.
- Define uma superfície Git pequena e reutilizável por variantes GitLab e Azure DevOps.
