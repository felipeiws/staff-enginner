# ADR-007: Markdown como fonte de verdade documental

Status: Accepted

## Decisão

ADRs, Design Documents e documentação arquitetural são Markdown versionado no repositório; visualizações e índices são derivados.

## Por quê

Review por PR, histórico Git, portabilidade e contribuição offline são mais importantes que edição rica centralizada. A plataforma pode indexar Markdown, mas não substitui sua autoria versionada.

## Consequências

Exige convenções e validação de links. O benefício é transparência e uma fonte de verdade que acompanha o código.
