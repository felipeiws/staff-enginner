# Registro de decisões

Este diretório recebe decisões de produto/operação que não tenham estabilidade ou alcance suficientes para ADR. Uma vez que uma decisão torna-se estrutural, promova-a para `docs/adr/`.

Registre data, contexto, responsável, evidência, decisão, validade e vínculo a issue/ADR. Isso preserva o raciocínio sem poluir a arquitetura com notas efêmeras.
